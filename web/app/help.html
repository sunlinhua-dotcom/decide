怎么用

Claude 有需要你拍板的东西，就推一张卡片到这里。一次只看一张：看图，点通过或返修，自动跳到下一张。你的选择会直接传回发卡的那个 Claude 对话。

一张卡片

大号数字卡片编号，如 07。全局唯一，在对话里说「07」就能指这一张。
标题镜号或主题加一句描述。标题上方的小字是哪个项目推来的；下面一行灰字是补充。
选择题没有图的问题（用哪台机器、走哪个方案、确认开工）会把每个选项画成一块大卡片：问题在最上面，卡片里写这个选项要多久、花多少、有什么风险，标「推荐」的是 Claude 建议的。点卡片或按 1–9 就选；每张选项卡右下角都有「要改…」：选它，但附一句哪里要改（快捷键 Shift + 数字）；多选题点几张再按「确定」；点红色的「要改」选项会弹出意见框。有示意图时图在上、选项卡在下。
图片几张就并排几张：按张数和长宽自动排，3 张一行 3 张，4 张竖图一行 4 张，6 张排 3×2，取让每张最大的那种排法。说明里带红点的是出问题的那一版（如「上次崩的」）。电脑上鼠标移到图上会出现放大镜看细节，滚轮调倍数。点图打开图层：3 张以上默认「并排」看全部，每张都能用放大镜，点其中一张单独看，底部「并排看 N 张」再切回来；右上角 ×、点空白处或按 Esc 关；图层底部也能直接点通过 / 返修或选这张；两张图能叠在一起拖线对比。手机上在图层里点图放大、拖动看细节，再点还原。
按钮审图卡只有两个：通过、返修。点返修会弹出写意见的框，写完回车提交（Shift + 回车换行，Esc 取消），意见跟着返修一起传给 Claude；不写直接点「提交返修」也行。选择题（A / B / C）点下面的字母，或点图打开后点「选 A」；每张候选图下面也有「要改…」，选这张并写意见。纯文字问题点选项。可多选的卡选完再点「确定」。
底下一行补充信息：审片卡是画面里有什么、上次崩在哪、这次怎么改；别的卡按需要写。
最下面的小图这个队列里剩下的卡，点一下跳过去，不用按顺序定。

点错了？底部提示条上有「撤回」，10 秒内都能点；也可以按 Z，或去「已定」页点「撤回重定」。

想回头看定过的卡：去「已定」页点任意一行，原样打开图、视频和选项，当时选的那项标黑，只看不问意见；← → 翻上一张、下一张，Esc 回列表。觉得要改再点「返修」（或按 R）写哪里要改，意见会交回推这张卡的 Claude 会话，并附上原来选的。

搜已定的卡：「已定」页顶上的搜索框边打边搜，编号、标题、选项、你选的、写过的意见都算，字打错一两个也找得到，命中的字标黄；按回车改成按意思找（交给服务器配置的对话模型，只发文字摘要，不发图和视频；没配就只有模糊搜索），适合只记得大意的时候，比如「上周那张吊顶比例的」。在已定页按 / 直接跳到搜索框，Esc 清空。

说话代替打字：「要改…」「在这里写意见」「返修」旁边和意见框里都有话筒。按住说话、松开就变成文字填进意见框；也可以点一下开始、再点一下（或点顶上浮条的「说完了」）结束，最长 60 秒，Esc 取消。文字只填进框里不会自动提交，看一眼再回车。录音只用来转文字，不保存。第一次用浏览器会问能不能用麦克风，点允许。

顶栏只列有待定卡的项目，每个项目一块颜色，颜色互不重复；有待定时「全部」是红块。卡片标题旁的项目名前面也有同色圆点，一眼分清是哪个项目的。

点了「在对话里说」的卡，如果 15 分钟内你没在那个 Claude 对话里发消息，顶上会出一条红色提醒（浏览器允许通知的话也弹系统通知）：点「我去说」不再提醒，「再等 15 分钟」顺延一次，「放回板上定」把这几张恢复成待定、直接在板上点。

在对话里说

返修意见可以直接写在网页上的意见框里。你也可以只在副屏上看，意见回到 Claude 对话里打：

  • 在网页上点「这 3 张在对话里说」（快捷键 C），这一组卡一起消失，Claude 会知道你要在对话里说。
  • 或者直接在对话里说，Claude 会自己把它推的卡从这里清掉。要指某一张就带编号，如「07 返修，字再大一点」。
  • 不想切回对话：点「在这里写意见」（快捷键 W），不用选现成选项，直接在板上写全部修改，回车提交。
  • 多选卡：点卡片或按数字勾选，底下一条显示已选几项，回车或「确定」提交；要附意见点「确定并写意见」。

Claude 授权卡

本机任何一个 Claude 会话要你允许命令、改文件、用 MCP 工具，或者向你提问、请你批准计划、问要不要开新会话，都会在「Claude 授权」这一栏出一张卡，排在最前面。标题是工具和一句话，下面是完整命令或改动（长的先折叠），信息栏写项目、会话和目录。

  • 按 1 允许、2 本会话一直允许（卡上写着管到哪些命令，关掉会话就失效）、3 拒绝。拒绝可以附一句意见，Claude 会照着改。
  • 同一个请求在 Claude 自己的对话框里也能答，哪边先答算哪边，另一边的卡自动消失。
  • 授权卡答完 Claude 就继续了，所以没有撤回，也没有「在对话里说」。命令里像密钥、密码的片段在卡上打了码，Claude 收到的还是原命令。

怎么传回 Claude

发卡的 Claude 对话在后台挂着一个监听。你一点，答案就送到那个对话，它接着干活。提示条会告诉你送到没有：

已传给 Claude对话正在等，马上就收到了。
Claude 下次查看时收到对话暂时没在等（比如正在跑别的活），答案已经存好，它下次查看就会拿到，不会丢。
已记下这张卡不属于某个对话（比如手动推的），只记录结果。

快捷键

1 2 …按顺序选第几个按钮。审图卡里 1 是通过，2 是返修（弹出意见框）。
Shift + 数字选第几个，并弹出意见框写哪里要改（通过 / 返修卡不用，返修本身就带意见框）。
C这一组在对话里说。
← →上一张、下一张（只是翻看，不算定）。手机上左右滑。
Z撤回刚才那一下。
O 或空格看大图。大图里 ← → 换图，Esc 关。
Enter多选卡提交。
?打开这页。

多个项目

顶部一排是项目，数字是还剩几张待定。「全部」把所有项目排成一个队列。

  • 每个项目一个窗口：点项目名后把地址拖成新窗口，或直接开 你的决策板地址/p/项目名。几个窗口各管各的，互不影响。
  • 四宫格：一屏同时看四个项目，各自一张卡。左上角下拉换项目；点哪一格，键盘就作用在哪一格。
  • 归档：做完的项目在「已定」页底部归档，就不再出现在顶部，随时能恢复。

派活

反过来，你也可以从这里把活交出去。顶部「派活」（只有接了分拣台才出现）：粘客户原话、写要做的事，加附件，点交给分拣台。分拣台判断这件事该给哪个 Claude 会话，再推一张卡来请你确认，确认后才投递。

  • 手机：点「＋ 附件」可以直接拍照、从相册选，或从「文件」里挑；一次最多 30 个，单个不超过 95 MB。
  • 电脑：文件拖进框里，或截图后直接粘贴。
  • 附件一加就开始上传，传完才能交。没交出去的会在下面「最近交的」里标红，点重试即可。

手机

按钮固定在屏幕底部，大拇指够得着；图上下排，左右滑翻页。Safari 里点「分享 → 添加到主屏幕」，以后像 App 一样打开。新卡片来时页面会自己刷新，开着就行。

别的设备登录

在手机、iPad 或别的电脑上打开你的决策板地址，输入密码（服务端设了 DECIDE_PASSWORD 时）或密钥就进来了，登录一次能保持一年。输错 5 次会锁 10 分钟。

常见问题

左上角 decide 旁边有个点？黄点是正在重连，红点是连接断了。一般会自己恢复，不行就刷新。

页面在后台，有新卡怎么知道？标签页标题会闪「● 新卡片」，括号里的数字是待定张数。

点完 Claude 没反应？看提示条。如果是「Claude 下次查看时收到」，在对话里随便说一句「看看 decide」，它就会去取。

视频卡怎么看？直接在卡片里播放；要全屏点「放大」。

给 Claude 的命令

这些是 Claude 在终端里用的，你一般不需要。

# 审一张图：通过 / 返修
decide ask -p film-ep1 -t "T12 杯子特写 · 手柄朝右" --before old.jpg --after new.jpg \
  --products "咖啡杯" --crash "手柄断了" --fix "换了参考图"

# 挑一张：点图即选
decide pick -p film-ep4 -t "01 外观 · 哪张光影最好" \
  --choice "A::a.jpg" --choice "B::b.jpg" --choice "C::c.jpg"

# 等你在网页上点（放后台，每次返回后重新挂）
decide listen

# 你在对话里打「07 返修 …」时，Claude 用这条记下
decide resolve 07 返修 字再大一点

decide ls                       # 看待定和最近定过的
decide help                     # 完整命令说明
